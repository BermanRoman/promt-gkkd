# Как подключить Wordstat к Claude

Редакция безопасности: 2026-11-06 — раздельные ветки существующей и новой установки, запрет перезаписи секретов и запускалки при повторе.

**Что это:** пошаговая инструкция для эксперта-новичка. После неё агент «Разведчик» системы Фиксик сам смотрит спрос в Яндекс Wordstat (режим А в `agents/02-razvedchik.md`). Без подключения Разведчик работает в режиме Б: просит у тебя скриншоты Wordstat (`knowledge/market.md`, 7.3).

**Кому подходит:** у тебя Mac и Claude Code (как в README) или приложение Claude для компьютера. Путь проверен на Mac с процессором Apple. Windows в исходном чате не проверяли.

**Основание:** чат Романа о подключении и его рабочая установка сервера (сверено 2026-10-05). Нужен только Wordstat, Директ не подключается.

**Сколько времени:** около часа, если всё идёт ровно. У Романа от создания приложения до первой цифры из Wordstat прошло примерно 45 минут, из них половина — разбор ошибок, описанных ниже.

---

## 0. Сначала честно про ограничения

- Официального коннектора Яндекса в Claude нет. Подключение идёт через сторонний сервер (MCP-сервер) с открытым кодом, который ставится на твой компьютер.
- Работает в Claude Code и в приложении Claude для компьютера. В браузерной версии claude.ai и в телефоне такой сервер не подключается.
- Компьютер должен быть включён, а Claude Code (или приложение Claude) — запущен, пока Разведчик работает. Ноутбук уснул — связь пропала, Разведчик переходит в режим Б.
- Нужна банковская карта: Wordstat по API живёт в Яндекс Облаке, а там без платёжного аккаунта не пускают. Деньги небольшие (см. п. 3), но карту привязать придётся.
- Нужен Терминал: придётся выполнить несколько блоков команд, проверить выбранный путь и ввести настройки в скрытые поля. Для существующей установки создание пропускается.
- Аккаунт и деньги в Яндекс Директе не нужны.

Если что-то из списка не подходит — не подключай. Разведчик отработает и без интеграции, только попросит скриншоты (п. 7).

---

## 1. Что понадобится

- Mac с Claude Code (или приложением Claude для компьютера).
- Аккаунт Яндекса (подойдёт Яндекс Почта). Всё делай под одним и тем же аккаунтом от начала до конца.
- Банковская карта для Яндекс Облака.
- Блокнот, куда выпишешь два несекретных значения: ClientID и ID каталога.
- Менеджер паролей или защищённая заметка для двух секретов: OAuth-токена и API-ключа.

**Главное правило про секреты.** OAuth-токен и API-ключ никому не показывай: ни в чат с Claude, ни в мессенджер, ни на скриншотах. Токен даёт доступ к твоим данным в Яндексе. ClientID и ID каталога — не секретные, их можно присылать.

## 2. Приложение в Яндексе и токен

Это «паспорт» для программы, которая будет ходить в Яндекс от твоего имени.

1. Открой oauth.yandex.ru и войди в свой аккаунт Яндекса.
2. Нажми «Создать приложение».
3. На вопросе о типе приложения выбери «Для доступа к API или отладки». Первый вариант — для сайтов с входом через Яндекс, он не подходит.
4. Название — любое, например `Wordstat MCP`. Его видишь только ты.
5. Почта для связи — твоя.
6. В разделе «Доступ к данным» начни вводить и отметь `cloud:auth` (Яндекс Облако). Доступы к Директу, Метрике и Аудиториям не отмечай.

   Зачем вообще токен, если Wordstat работает по API-ключу из п. 3: сервер не запускается без токена в настройках. Wordstat этот токен не использует.
7. Redirect URI подставится сам. Ничего не меняй.
8. Нажми «Создать приложение».
9. Скопируй в блокнот ClientID — строку из букв и цифр. Client secret не нужен, никому его не показывай.
10. Открой в браузере ссылку, подставив свой ClientID:

        https://oauth.yandex.ru/authorize?response_type=token&client_id=<ваш ClientID>

11. Нажми «Разрешить» или «Войти как …».
12. На странице появится токен — длинная строка, обычно начинается с `y0_`. Скопируй его в менеджер паролей. В чат не вставляй.

**Если токен засветился** (отправил в чат, на скриншоте, в мессенджере): открой id.yandex.ru/personal/data-access, найди своё приложение, нажми «Отключить». Все его токены перестанут работать. Потом получи новый токен по ссылке из п. 10.

## 3. Яндекс Облако: каталог и ключ для Wordstat

1. Открой console.yandex.cloud под тем же аккаунтом Яндекса.
2. Создай платёжный аккаунт и привяжи карту. Цены на 2026-09-20, по данным из чата: 20 ₽ за 1000 запросов топа и динамики, 50 ₽ за 1000 запросов по регионам, справочник регионов бесплатный. Один прогон Разведчика — это 20–25 запросов, то есть меньше рубля. [ДОПУЩЕНИЕ] Новым аккаунтам Облако иногда даёт стартовый грант — у Романа было 4 000 ₽ грантов, расход шёл из них. Будет ли грант у тебя, заранее не известно.
3. Слева открой каталог — обычно он называется `default`.
4. Найди ID каталога — строка вида `b1g…` вверху страницы каталога. Скопируй в блокнот.
5. Открой страницу сервисных аккаунтов именно этого каталога. Прямая ссылка:

        https://console.yandex.cloud/folders/<ваш ID каталога>/iam/service-accounts

6. Нажми «Создать сервисный аккаунт».
7. Имя — `wordstat-mcp`, только латиницей.
8. Нажми «Добавить роль», начни вводить `search-api` и выбери `search-api.executor`.
9. Нажми «Создать».
10. Нажми на созданный аккаунт в списке.
11. Вверху нажми «Создать новый ключ» → «Создать API-ключ». Не «авторизованный» и не «статический», а именно API-ключ.
12. Если спросят область действия — выбери `yc.search-api.execute`. Списка нет — оставь как есть.
13. Нажми «Создать».
14. Появится секретный ключ. Он показывается один раз. Сразу скопируй его в менеджер паролей. Закрыл окно, не скопировав, — удали ключ и создай новый.

Почему не токен из п. 2: токены, выпущенные после 1 июня 2026, Яндекс больше не меняет на облачные. Для Wordstat нужен именно API-ключ сервисного аккаунта.

## 4. Сервер на компьютере

**Повторное подключение начинается с проверки установки, а не с клонирования.** Сначала выясни полный путь уже установленного Wordstat MCP по действующему подключению и несекретной документации сервиса. Проверь, что это нужный сервис Яндекс Wordstat, а не другая программа с похожим именем; наличие папки само по себе этого не доказывает. Не присылай конфиги с секретами и не выводи `.env`. Если назначение или путь неизвестны — остановись и уточни их, ничего не устанавливай поверх.

Для дальнейших команд в одном окне Терминала задай назначенный полный путь; пример для новой установки:

```sh
export WORDSTAT_DIR="$HOME/yandex-ads-mcp"
unset WORDSTAT_NEW WORDSTAT_READY
```

Если по этому пути уже что-либо есть, включая ссылку или неполную установку, **не выполняй создание из §4–5**. После проверки пути и назначения используй существующий `run.sh` и переходи к §6; отсутствие рабочего запуска — отдельная диагностика без перезаписи `.env`, `run.sh`, окружения и конфигов. Не удаляй каталог и не выбирай новое место молча, чтобы обойти ошибку.

Ветка новой установки ниже предназначена только для отсутствующего назначенного каталога. Остановись при любой ошибке: следующий этап разрешён только после явного сообщения об успехе предыдущего.

Используем открытый сервер Yurich-ru/yandex-ads-mcp (github.com/Yurich-ru/yandex-ads-mcp, лицензия MIT). Роман перед установкой проверил код 2026-09-20: сервер обращается только к доменам Яндекса, токен уходит только в заголовок авторизации Яндекса. Код с тех пор мог измениться.

Не ставь похожие пакеты через `npx` с названиями вроде `yandex-direct-mcp` без автора: часть таких имён на npm занята посторонними издателями, и твой токен уйдёт в чужой код.

1. Открой Терминал: Cmd+Пробел, напиши «Терминал», Enter.
2. Проверь версию Python. Вставь и нажми Enter:

        python3 -V

3. Если версия 3.10 или выше — переходи к шагу 5. Если 3.9 или ниже (на Mac обычно 3.9.6) — серверу этого мало, нужен свежий Python.
4. Поставь свежий Python: скачай установщик с python.org (раздел Downloads → macOS) и установи как обычную программу. Если у тебя есть Homebrew, можно командой `brew install python`. Потом снова проверь версию — команда из шага 2, но с полным путём: `/usr/local/bin/python3 -V` после python.org или `/opt/homebrew/bin/python3 -V` после Homebrew. Этот полный путь дальше подставляй вместо `python3`. [ДОПУЩЕНИЕ] Роман ставил через Homebrew; путь через python.org в чате не проверяли.
5. Скачай сервер только в новый назначенный каталог. Проверка и `mkdir` не позволят клонировать поверх существующего пути; при ошибке маркер новой установки не выставляется:

```sh
unset WORDSTAT_NEW WORDSTAT_READY
if [ -z "${WORDSTAT_DIR:-}" ]; then
  echo 'Сначала задай WORDSTAT_DIR' >&2
elif [ "${WORDSTAT_DIR#/}" = "$WORDSTAT_DIR" ]; then
  echo 'Нужен полный абсолютный путь: создание не выполнялось' >&2
elif [ -e "$WORDSTAT_DIR" ] || [ -L "$WORDSTAT_DIR" ]; then
  echo 'Путь уже существует: создание пропущено; проверь установку и переходи к ветке существующей' >&2
elif mkdir -- "$WORDSTAT_DIR" && git clone https://github.com/Yurich-ru/yandex-ads-mcp.git "$WORDSTAT_DIR"; then
  export WORDSTAT_NEW="$WORDSTAT_DIR"
  echo 'Новый сервер скачан'
else
  echo 'Создание не завершено: дальше не продолжай; существующие файлы не удаляй' >&2
fi
```

   Если Mac предложит установить «инструменты командной строки» — дождись конца установки. После неудачи сначала проверь, остался ли каталог: повтор блока не пишет поверх него. Неполная установка требует отдельной диагностики.
6. Поставь библиотеки сервера. Вместо `python3` — путь из шага 4, если ставил свежий Python:

```sh
unset WORDSTAT_READY
if [ -n "${WORDSTAT_DIR:-}" ] && [ "${WORDSTAT_NEW:-}" = "$WORDSTAT_DIR" ]; then
  if (cd "$WORDSTAT_DIR" && python3 -m venv venv && ./venv/bin/pip install -q --upgrade pip && ./venv/bin/pip install -q -r requirements.txt && ./venv/bin/python -c "import mcp, httpx"); then
    export WORDSTAT_READY="$WORDSTAT_DIR"
    echo 'библиотеки на месте'
  else
    echo 'Подготовка не завершена: к секретам не переходи' >&2
  fi
else
  echo 'Нет подтверждённой новой установки: окружение не изменено' >&2
fi
```

   Жди строку «библиотеки на месте».

## 5. Настройки и секреты

Этот раздел выполняется **только для успешно подготовленной новой установки** из §4. Для существующей установки его пропусти: здесь нельзя обновлять её секреты или запускалку.

Секреты создаются одним новым файлом `.env` с правами 600; ввод в Терминале не отображается. В настройки Claude токен не попадает. Команда отказывается читать или заменять уже существующие `.env` и `run.sh`, включая ссылки; повторный запуск не служит способом обновить ключ.

1. Вставь блок целиком. По запросу введи несекретный ID каталога, затем вставь OAuth-токен и API-ключ из менеджера паролей в скрытые поля ввода. Не вставляй секреты в текст самой команды или в чат.

```sh
if [ -n "${WORDSTAT_DIR:-}" ] && [ "${WORDSTAT_READY:-}" = "$WORDSTAT_DIR" ]; then
  "$WORDSTAT_DIR/venv/bin/python" - <<'PY'
import getpass, os, pathlib, re, shlex
root = pathlib.Path(os.environ['WORDSTAT_DIR'])
paths = [root / '.env', root / 'run.sh']
if any(os.path.lexists(p) for p in paths):
    raise SystemExit('Файл уже существует: ничего не прочитано и не заменено; остановись')
with open('/dev/tty', 'w') as tty_out:
    tty_out.write('ID каталога: '); tty_out.flush()
with open('/dev/tty', 'r') as tty_in:
    folder = tty_in.readline().strip()
if not re.fullmatch(r'[A-Za-z0-9_-]+', folder):
    raise SystemExit('Некорректный ID: файлы не созданы')
token = getpass.getpass('OAuth-токен (скрытый ввод): ').strip()
key = getpass.getpass('API-ключ (скрытый ввод): ').strip()
if not token or not key or any(c.isspace() for c in token + key):
    raise SystemExit('Пустой или некорректный секрет: файлы не созданы')
settings = '\n'.join(['YD_OAUTH_TOKEN=' + shlex.quote(token),
    'YC_FOLDER_ID=' + shlex.quote(folder), 'YC_API_KEY=' + shlex.quote(key),
    'YD_READONLY=true', 'YD_CONFIRM=true', 'YD_SANDBOX=false', 'YD_LOG_LEVEL=INFO', ''])
launcher = '''#!/bin/bash
cd -- "$(dirname -- "$0")" || exit 1
[ -f .env ] || { echo "Нет файла .env рядом с run.sh" >&2; exit 1; }
set -a
. ./.env || exit 1
set +a
exec ./venv/bin/python server.py
'''
for path, content, mode in [(paths[0], settings, 0o600), (paths[1], launcher, 0o700)]:
    fd = os.open(path, os.O_WRONLY | os.O_CREAT | os.O_EXCL, mode)
    with os.fdopen(fd, 'w') as out:
        out.write(content)
print('Новые .env и run.sh созданы; секреты не выведены')
PY
else
  echo 'Нет успешно подготовленной новой установки: файлы не изменены' >&2
fi
```

Создание каждого файла использует исключительный режим: даже если файл появится после предварительной проверки, существующий не будет перезаписан. При любой ошибке остановись; частично созданные файлы не удаляй и не перезаписывай автоматически. Нужна отдельная диагностика без показа секретов.

2. Проверку реального запуска проводи только после завершения настройки и подтверждения правильного пути; не публикуй сырой журнал, если в нём могут оказаться секреты. Подключение и запросы в §6 выполняй отдельно, когда готов обращаться к сервису. Эта инструкция сама по себе не подтверждает успешный запуск новой установки.

Что значат настройки: `YD_READONLY=true` запрещает серверу что-либо менять в Директе — для Wordstat это ничего не ограничивает, но защищает рекламный кабинет, если он есть. `YD_CONFIRM=true` — на случай, если снимешь запрет: любое изменение сначала покажет предпросмотр.

## 6. Подключение к Claude и проверка

Во всех примерах используй проверенный полный путь из `WORDSTAT_DIR`, а не обязательно `~/yandex-ads-mcp`. Существующие секреты и запускалку не меняй. Совпадающее подключение оставь как есть; занятое другим сервером имя не заменяй. Отсутствующую запись добавляют отдельно, сохраняя остальные подключения; не копируй пример поверх всего конфига.

**Если работаешь в Claude Code** (вкладка Code в приложении Claude, как в README, или терминал):

1. Claude сам создаёт в рабочей папке файл `.mcp.json` — подключение сервера к этой папке. Путь к `run.sh` — полный, без `~`:

        {"mcpServers": {"yandex-ads": {"command": "/Users/<имя>/yandex-ads-mcp/run.sh"}}}

   Файл уже есть — сначала проверить запись `yandex-ads` без показа секретов: совпадает — ничего не записывать; отличается — остановиться и выяснить назначение. Если записи нет, Claude добавляет её по прямому запросу, не стирая остальное.
2. Начни новую сессию в той же папке: во вкладке Code — новая сессия с той же папкой, в терминале — `/exit` и снова `claude`. При первом запуске Claude спросит, доверяешь ли ты серверу `yandex-ads` из этой папки, — отвечай «да».
3. Напиши `/mcp` — в списке должен быть `yandex-ads` со статусом «connected». Дальше — шаги 4–5 ниже.

[ДОПУЩЕНИЕ] Подключение через `.mcp.json` во вкладке Code приложения на живой машине не проверялось. Не подхватилось — используй вариант для приложения Claude ниже.

**Если работаешь в приложении Claude для компьютера:**

1. Вставь команду — она добавит сервер в настройки приложения Claude, сохранив остальные подключения. Совпадающий `yandex-ads` переиспользуется; если это имя уже занято другой конфигурацией, команда остановится без записи. Сначала выясни, какой сервер используется; рабочее подключение не заменяй молча:

        "$WORDSTAT_DIR/venv/bin/python" -c "import json,os,pathlib,sys; root=pathlib.Path(os.environ['WORDSTAT_DIR']); root.is_absolute() and (root/'run.sh').is_file() or sys.exit('Сначала проверь полный путь и запускалку'); p=pathlib.Path(os.path.expanduser('~/Library/Application Support/Claude/claude_desktop_config.json')); p.parent.mkdir(parents=True,exist_ok=True); d=json.loads(p.read_text() or '{}') if p.exists() else {}; servers=d.setdefault('mcpServers',{}); desired={'command':str(root/'run.sh')}; existing=servers.get('yandex-ads'); existing!=desired or sys.exit('Подключение уже совпадает: конфиг не изменён'); 'yandex-ads' not in servers or sys.exit('Имя yandex-ads уже занято: настройки сохранены без изменений; сначала проверь действующее подключение.'); servers['yandex-ads']=desired; p.write_text(json.dumps(d,indent=2,ensure_ascii=False)); print('конфиг записан:', p)"

2. Полностью закрой Claude: Cmd+Q. Просто закрыть окно мало — сервер подхватывается только при запуске приложения.
3. Открой Claude заново.
4. Открой новый чат и напиши:

        Через Wordstat покажи дерево регионов и найди в нём ID Москвы.

   Этот запрос бесплатный. Пришёл список регионов — авторизация в Облаке работает.
5. Напиши второй запрос:

        Через Wordstat покажи топ-20 запросов по фразе «как похудеть» по всей России за последние 30 дней.

   Пришла таблица фраз с числами — всё готово. Разведчик будет работать в режиме А.

В среде Романа инструменты видны агенту под именами `mcp__remote-devices__yandex-ads__yd_wordstat_*` (`top_requests`, `dynamics`, `regions`, `regions_tree`). Префикс в другой среде может отличаться — Разведчик ищет их по слову «wordstat».

## 7. Типовые ошибки

- **`Could not find a version that satisfies the requirement mcp`** при установке библиотек. Проверь, не ниже ли Python 3.10. Подготовка не завершена: к §5 не переходи. Не удаляй окружение существующей установки; сначала проверь выбранный Python и состояние новой папки, затем отдельно согласуй восстановление.
- **`zsh: no matches found`** в команде с `ls` и звёздочкой. zsh обрывает команду, если путь не найден. Это не поломка, просто команда не досмотрела до конца.
- **`read: -p: no coprocess`**. Команда с `read -p` написана для bash, а на Mac по умолчанию zsh. В §5 скрытый ввод реализован через Python, без `read -p`.
- **`zsh: command not found: y0_…`**. Ты вставил токен в Терминал как команду. Токен засветился в истории Терминала. Отзови его (п. 2, «Если токен засветился») и получи новый.
- **`Нет файла .env рядом с run.sh`**. Не запускай создание повторно вслепую. Проверь выбранный путь и завершённость новой установки без показа содержимого файлов; существующую установку диагностируй отдельно.
- **`YD_OAUTH_TOKEN environment variable is required`**. Проверь путь и способ передачи настроек без вывода токена. §5 не обновляет существующий `.env`; замена секрета — отдельное действие владельца установки после диагностики, без перезаписи остальных настроек.
- **Сервер в Claude не появился.** Claude не перезапускали полностью. В Claude Code — `/exit` и запустить снова; в приложении — Cmd+Q и открыть заново.
- **Сервер запустился, а Wordstat отвечает ошибкой авторизации.** Возможны проблемы ключа, прав или выбранного каталога. Проверь их без показа ключа; не пересоздавай ключи и `.env` вслепую. После подтверждённого исправления владельцем перезапусти Claude.
- **Не та вкладка в Облаке.** «Права доступа» на уровне всего облака — не то место. Сервисные аккаунты создаются внутри каталога, ссылка в п. 3, шаг 5.
- **Запрос с регионом падает, без региона работает.** У Романа сервер отправлял номер региона числом, а Wordstat ждёт строку. Роман исправил это в своей копии сервера. [ДОПУЩЕНИЕ] Исправлено ли это в исходном репозитории — не известно. Для онлайн-продуктов регион не нужен, Разведчик берёт всю Россию. Для офлайна — попроси Claude проверить и поправить передачу региона в коде сервера, потом Cmd+Q.
- **Ошибка 400 про формат даты в динамике.** Конец периода должен быть последним днём полного месяца, а не 1-м числом. Разведчик это учитывает (`knowledge/market.md`, 7.2).
- **Проверка квоты возвращает 404.** Инструмент `yd_wordstat_user_info` с августа 2026 не работает на стороне Яндекса. На остальные запросы это не влияет.
- **Всё работало, потом пропало.** Закрылось приложение Claude или уснул компьютер. Открой Claude, убедись, что компьютер не спит.

## 8. Если не получилось

Ничего страшного: Разведчик не останавливается. Он работает в режиме Б.

- Разведчик пришлёт 3–5 фраз и инструкцию, как снять скриншоты с wordstat.yandex.ru — это бесплатно, нужен только аккаунт Яндекса. Займёт 10–15 минут (`knowledge/market.md`, 7.3).
- Пока скриншотов нет, выводы о спросе помечены `[ДОПУЩЕНИЕ: до данных Wordstat]`.
- Не хочешь возиться — напиши Фиксику «пропустим». Выводы будут осторожнее, работа продолжится.
- К подключению можно вернуться позже: начни с проверки существующего пути и подключения; повторно создавать секреты и запускалку не нужно.
