## 0. Правила для всех цепочек

1. **Срок реальный.** У срока есть дата, время и проверяемая причина: старт потока, места, цена по оферте, конец условий практикума (инфостиль 9.4, M§7.3). После срока условие действительно исчезает: ссылка на оплату перестаёт работать, бонус снимается, цена меняется для всех. Таймер на нуле при работающей странице — враньё.
2. **«Последнее» значит последнее.** Сообщение «больше не пишу об этом» закрывает тему тегом `последнее_<продукт>`. По этой теме бот больше не пишет ничем: ни цепочкой, ни предложением этого продукта в сообщениях канала и бота (Ц-12), ни напоминанием. Второе «последнее» по той же теме не ставится. Вернуть тему может только сам человек: написал или нажал ссылку.
3. **Одно состояние — одна цепочка.** При смене состояния старая цепочка снимается: оплатил — окно и дожимы удаляются, кликнул — клик-цепочка обрывается (Б-3).
4. **Каждое касание — новый повод и ценный материал.** Напоминание без новой информации превращается в упрёк (инфостиль 10.5). Не писать «напоминаю в третий раз».
5. **Частота:** в боте не чаще одного сообщения в день по таймеру; ответ на действие человека не считается; плотнее — только отметки до закрытия ссылки и последний день реального срока (M§4.2, Р-11). В мессенджере каждое сообщение — уведомление, поэтому почтовые нормы частоты (несколько писем в день) не переносятся.
6. **Продажа холодным — не раньше порога потребления** (Б-11, M§4.12). До порога бот отвечает на прямой вопрос о цене сразу и честно, но продающих цепочек не запускает.
7. **Одна повторная волна.** После окна — одна волна с новым реальным условием (Ц-6), затем «последнее сообщение» и канал (M§7.8, Р-8). Лестницы сроков и серии продлений нет.
8. **Отказник не выпадает.** Не купил — уходит в канал эксперта (Ц-12), а не в новый дожим. Возвращается, когда снова поднял руку действием (M§1.2, M§7.9).
9. **Разнос по времени.** Массовые рассылки идут волнами (14:00 / 14:05 / 14:10, модуль РБХ), чтобы не получить пик отписок.
10. **Право уйти.** В каждой цепочке работают `/stop` и отписка. Бан за отписку от канала — опция Б-6, по умолчанию включена `[ДОПУЩЕНИЕ: по умолчанию включено — по опыту Романа]`, эксперт может выключить (В-30).
11. **Стоп-правила Контролёра.** Без искусственной срочности, выдуманных якорей и цифр, медицинских обещаний. Рост цены после окна — только до реальной цены продукта.
12. **Процедуры — в служебных сообщениях.** Согласия, `/stop`, условия обработки данных не встраиваются в продающие касания (M§9, правило 5).

Путь — общий скелет (`library/funnel-types.md`, 0.6). Модули — `library/modules.md`.

|---|---|---|---|
| Пришёл из ролика | переход по ссылке или слову | первое сообщение (В-2), согласие на продолжение и вопрос-«корзина» (Б-10) | «да» или «нет» |
| Сказал «нет» в префрейме | ответ «нет, спасибо» словами | ссылка на канал (Ц-12) | — |

| Порог пройден | `порог_пройден` | приглашение в ближайший поток практикума (Б-11, Ц-14) | запись на практикум |
| Не открыл приглашение, условия, запись | не было клика | клик-цепочка (Ц-2), затем повтор под другим углом | клик |
| Записан на практикум | `##ПРАКТИКУМ##` | напоминания и задания (Ц-3, Ц-14) | конец практикума |

| Вход или продукт ниже 1 медианы | получил, прошёл или купил | вовлечение «выгода — логика — причина» (Ц-4) | покупка или «последнее сообщение» |
| Взял ссылку, не оплатил | `ссылка_выдана` | отметки до закрытия ссылки (Ц-5); «остались вопросы?» (Б-5) | оплата или закрытие ссылки |
| Ответил на «остались вопросы?» | ответ | живой ответ эксперта (Б-5), тег `ждёт_ответа` | ответ человека |
| Сказал «подумаю», назвал дату | `##НАПОМНИТЬ:дата##` | одно сообщение в эту дату; до неё — пауза | ответ |
| Окно закрылось, `волна = 0` | конец окна | повторная волна (Ц-6) | оплата или конец волны |
| Волна закрылась | конец волны | «последнее сообщение» → канал (Ц-12); через 3–5 дней «давайте помогу» (О-2), если есть малая версия | — |
| Выше 2 медиан: заявка без записи | анкета заполнена, слот не выбран | дожим на запись (Ц-9) | запись |
| Записан на созвон | запись | прогрев перед созвоном (Ц-10) | созвон |
| Пропустил эфир | записан, не пришёл | серия «для пропустивших» (§2) | просмотр записи |
| Оплатил | `оплата` | онбординг 48 часов (Ц-11), шаг после оплаты (О-2) | конец первой недели |
| 2–3 недели после старта | дата по карте | контрольная точка и отзыв (Ц-15) | ответ на опрос |
| ~90 дней после покупки | дата по карте | следующая ступень (Ц-16) | покупка или «нет» |
| 60 дней без действий | нет слов, ответов, переходов по ссылкам | повторное вовлечение, затем тишина (Ц-7) | реакция |

`[ДОПУЩЕНИЕ]` Состояния «бросил мини-диагностику на середине» и «записался на созвон, не пришёл»: одно сообщение со словами человека из разговора и вопросом, продолжить ли; нет ответа — канал (Ц-12).

## 2. Структуры цепочек

### Дожим по состоянию
- **Механика:** цепочка привязана не к календарю, а к состоянию человека. Каждое сообщение называет последнее действие, которое человек уже сделал, и предлагает один следующий шаг. Человек получает только то, что относится к нему сейчас.
- **Инфостиль:** «Вчера вы забрали [магнит]. Следующий шаг после него — [шаг], он про [одна единица результата]».
- **Условие честности:** прошлое действие реально записано ботом (Б-4). Не писать «вы интересовались», если человек только подписался.
- **Статус:** `гипотеза для холодных`.

### Серия прогрева
- **Механика:** 3–8 недель после подписки, одна единица в день (Ц-1, M§4.4). Единица — одна мысль, одна история, одно доказательство и действие-метка в конце: слово или ответ. Метки считаются (`единиц_потреблено`), по ним открывается продажа (Б-11).
  - **Петли:** каждая единица открывает конкретный вопрос, на который отвечает следующая. Конец единицы — «как я из этого выбрался — завтра; подсказка: дело было не в [то, что все пробуют]».
  - **Раскладка:** боль → надежда → возражения → хотелки → выгода → супервыгода.
  - **Большая костяшка и ложные убеждения:** одна вера, после которой падают остальные возражения; затем три ложных убеждения — о способе, о себе, о внешнем — по истории на каждое.
  - **«Это развод» — первым:** кто эксперт, реквизиты, что он не обещает, кому не подходит, как вернуть деньги.
  - **История происхождения** — один раз, в начале: «так было не всегда → стена → открытие → как сейчас». Дальше — истории клиентов.
- **Инфостиль:** «Здравствуйте, я [имя], [кто я одной строкой]. Здесь раз в день будет одна мысль из моей работы и одно задание на 5 минут. Остановить — /stop». Единица — речь эксперта из его роликов и разборов, а не маркетинговая структура.
- **Условие честности:** частота, обещанная в префрейме, соблюдается. Истории реальные; собирательный рассказчик помечен. Пустая интрига запрещена: открытый вопрос закрывается в следующей единице. Продажи до порога нет.
- **Статус:** `гипотеза для холодных`.

### Практикум
- **Механика:** бесплатные 3–5 дней с обязательным действием (Ц-14, Р-2). Приглашение — после порога, старт — в ближайшее общее окно потока. Каждый день одно задание и одна маленькая победа. В конце — предложение основного продукта с реальным сроком (окно).
- **Инфостиль:** «Практикум „[название]“ стартует [дата]. 5 дней, одно задание в день на 15 минут. Итог — [маленькая победа]. Бесплатно: потом расскажу про основную программу тем, кому она подойдёт».
- **Условие честности:** результат практикума реально достижим за эти дни. Полноту курса в практикум не переносить. Причина бесплатности — названа прямо.
- **Статус:** `гипотеза для холодных`.

### Клик-цепочка
- **Механика:** задача — не продать, а довести до одного клика: страница продукта, запись эфира, условия, урок (Ц-2, M§7.5). Одно сообщение в день, 3 дня. Кликнул — цепочка обрывается, человек переходит в следующее состояние. Не кликнул — норма: большинство просто не увидели.
- **Инфостиль:** «[Тема]: как [результат] без [главный страх]. Разбор на 20 минут: [ссылка]. В нём: [пункт 1], [пункт 2], [пункт 3]».
- **Условие честности:** то, что обещано за кликом, там действительно есть. Пункты — из содержания материала.
- **Статус:** `гипотеза для холодных`.

### Повтор клик-цепочки под другим углом
- **Механика:** не кликнул за 3 дня — не раньше чем через 2 дня одна новая цепочка к тому же материалу с другого угла: другая первая фраза, другая картинка. Основной текст можно оставить: человек его не открывал. Повтор — один, дальше канал.
- **Инфостиль:** первая цепочка — через результат («Как [результат] за [срок]»), вторая — через ошибку («Почему [типичное действие] не даёт [результат]») или через историю клиента.
- **Условие честности:** новый угол не обещает больше, чем материал даёт. Без интриги без содержания (инфостиль 13.5).
- **Статус:** `гипотеза для холодных`.

### Вовлечение «выгода — логика — причина»
- **Механика:** для входа и продуктов ниже 1 медианы (Ц-4, M§7.6). Три сообщения, одно в день, без пауз больше 24 часов. Выгода: «вы прошли [X], следующий шаг — [продукт]». Логика: «вы хотите [результат], иначе не начали бы; это логичное продолжение». Причина: реальный срок или, если срока нет, «больше не пишу об этом».
- **Инфостиль:** день 1 — «Вчера вы закончили [X]. Если цель — [результат], следующий шаг — [продукт]: [ссылка]». День 2 — «Вы пришли за [результат]. [Продукт] закрывает его первую часть: [что именно]». День 3 — «Это последнее сообщение про [продукт]. Дальше — в канале, о другом».
- **Условие честности:** без упрёков в нерешительности и давления виной. Причина — только реальный срок или реальное прекращение сообщений по теме.
- **Статус:** `гипотеза для холодных`.

### Окно основного продукта
- **Механика:** реальный срок по зоне цены (Ц-17, M§7.3): ниже 1 медианы — часы, ссылка живёт 2 часа; 1–2 медианы — около 24 часов на ссылку; основной продукт в окне потока — дни, меньше недели. Общее окно открывается для всех с пройденным порогом по дате потока; персональное — от момента, когда человек поднял руку. В первый день — одно спокойное сообщение с условиями. Дальше не чаще одного касания в день, в последний день — до 3–4: утро, за ~4 часа, за ~1 час. Порядок касаний: частые вопросы → мотивация → доверие → ценность → цена. Решения сгущаются к последним часам — поэтому плотнее к концу.
- **Инфостиль:** «Запись на [продукт] открыта до [дата, время]: [причина — старт потока]. Входит: [3 пункта]. Есть вопрос — напишите, отвечу». Последний день — темы-факты (§3).
- **Условие честности:** срок и условие реальные. Нет ни бонуса, ни скидки — срок привязан к реальному событию: старт потока, закрытие записи, конец набора в группу. Без реального срока окно не ставится.
- **Статус:** `гипотеза для холодных`.

### Отметки до закрытия ссылки
- **Механика:** человек сам взял ссылку, решение почти принято (Ц-5, M§7.4). Касания — за 60, 30, 15, 10, 5, 3 и 1 минуту до закрытия личной ссылки (решение Романа, В-27, В-45). Плотность растёт к концу срока. Касание на момент закрытия и позже не отправляется; финал «ссылка закрылась» — отдельным сообщением в момент закрытия. Оплата снимает цепочку.
- **Инфостиль:** «Ссылка на оплату работает до [время]. После — [что происходит по оферте]. Вопросы можно задать здесь».
- **Условие честности:** срок ссылки задан технически. После закрытия нельзя писать «с этого момента курс стоит [цена]», если это не реальная цена для всех (РБХ, В-15: якорь 25 000 ₽ не подтвердился и под запретом). Финал: «Ссылка закрылась. Если решите, напишите в этот чат — новая ссылка придёт по цене из оферты».
- **Статус:** `проверено в деле` для зоны ниже 1 медианы (РБХ: из 3 взявших ссылку оплатили 2).

### Повторная волна
- **Механика:** окно закрылось — не раньше чем через 2 дня одна волна с новым реальным условием (живой разбор, бонус, место в потоке) и своим реальным сроком (Ц-6, Р-8). Касания — как в окне. Срок волны прошёл — «последнее сообщение на эту тему» и канал. Волна одна: `волна = 1` — вторая не ставится.
- **Инфостиль:** «Открываю запись ещё на 2 дня, до [дата, время]: добавил [условие] для тех, кто запишется сейчас. Что это даёт: [одна фраза]».
- **Условие честности:** условие реальное, описано точно. Если волна запланирована, окно не говорит «больше не будет». Рассрочка есть с самого начала и стимулом волны не бывает. Причина — как есть, без драмы про упавший сервер.
- **Статус:** `гипотеза для холодных`.

### «Последнее сообщение»
- **Механика:** закрывает тему продукта для человека: тег `последнее_<продукт>`, событие `последнее_отправлено`. После него тема не возвращается ничем — ни цепочкой, ни предложением, ни напоминанием (M§7.8). Человек получает ссылку на канал.
- **Инфостиль:** «Это последнее сообщение про [продукт]. Ссылка на канал: [ссылка] — там [что публикую]. Следующий поток — [дата], о нём напишу в канале».
- **Условие честности:** по теме бот действительно больше не пишет. Одно «последнее» на тему.
- **Статус:** `гипотеза для холодных`.

### «Давайте помогу» через 3–5 дней
- **Механика:** человек сказал «нет» конкретному предложению, а не всему. Через 3–5 дней после «последнего сообщения» или отказа — одно сообщение с реальной малой версией продукта: разбор, консультация, короткий формат (M§7.9, О-2). Малой версии нет — сообщение не ставится.
- **Инфостиль:** «Если [продукт] сейчас не подходит, могу помочь иначе: [малая версия] — [одна фраза], [цена или бесплатно]».
- **Условие честности:** цена основного продукта при этом не меняется. Тем, кто «не подходит» по здоровью или сроку, ничего не продаём.
- **Статус:** `гипотеза для холодных`.

### Реальная скидка за пройденный путь
- **Механика:** честная версия якоря из РБХ (О-1). Цена продукта одна для всех и показана открыто. Тот, кто прошёл практикум или бесплатную часть, получает реальную скидку до реальной даты. Человек видит не обман системы, а награду за сделанное.
- **Инфостиль:** «[Продукт] стоит [цена]. Вы прошли [что прошёл], поэтому для вас до [дата] — [цена со скидкой]. После [дата] — [цена]».
- **Условие честности:** полная цена реально действует для всех, кто не прошёл путь, и после даты. Это не скидка за полную оплату (В-41).
- **Статус:** `из практики, цифр нет`.

### Онбординг 48 часов
- **Механика:** сразу после оплаты — приветствие живого человека: кто пишет, чего ожидать, что сделать сегодня (Ц-11, M§8.3). В первые 48 часов — первое действие и маленькая победа против сомнения «смогу ли я». Одно сообщение со следующим логичным шагом — если он есть. Дальше — по шагам первой недели, не чаще раза в день.
- **Инфостиль:** «Здравствуйте, это [имя]. Доступ: [ссылка]. Сегодня одно действие: [что], 15 минут. Напишите сюда, как получилось, — отвечу до [время]».
- **Условие честности:** честные ожидания без «результат в 100 раз». Купившему не продаём то, что уже входит в покупку.
- **Статус:** `из практики, цифр нет`.

### Контрольная точка и отзыв
- **Механика:** через 2–3 недели — опрос «что получилось / что мешает» (Ц-15, M§8.5). Недовольному — помощь. Довольному — просьба об отзыве и следующий шаг (основная допродажа, Р-9). Непокупка здесь — ещё и сигнал, что человеку нужна помощь.
- **Инфостиль:** «Прошло 3 недели. Что получилось, а что мешает? Ответьте парой слов — разберу».
- **Условие честности:** отзыв — только с согласием, в форме «было — задача — что сделали — результат». Отзыв не обменивается на скидку.
- **Статус:** `из практики, цифр нет`.

### Следующая ступень
- **Механика:** следующая большая продажа — примерно через 90 дней, человек знает о ней заранее (Ц-16, M§8.7). Предоплаченные сезоны с началом и концом, бесплатный чат выпускников, платная мастер-группа. Рекомендации — при покупке и после победы, как подарок другу.
- **Инфостиль:** «Сезон 2 стартует [дата]: [что будет]. Для выпускников — [условие]. Чат выпускников остаётся открытым».
- **Условие честности:** без автосписаний. Денежное вознаграждение за рекомендацию — только одноуровневое и только партнёрам-экспертам.
- **Статус:** `из практики, цифр нет`.

### Повторное вовлечение и тишина
- **Механика:** 60 дней без действий — слов, ответов, переходов по ссылкам `[ДОПУЩЕНИЕ: в Telegram открытия не видны]`. 7–15 дней: одно-два сообщения с лучшим, что есть; одно «тема ещё актуальна?»; затем тишина: тег `неактивен`, таймерные сообщения не уходят, человек остаётся в боте и в канале (Ц-7, Р-11).
- **Инфостиль:** «Вы давно не заходили. Тема ещё актуальна? Если нет — перестану писать. Канал остаётся: [ссылка]».
- **Условие честности:** после «перестану писать» действительно перестаём. «Подарки» — реально полезные материалы, а не перепакованный старый оффер.
- **Статус:** `гипотеза для холодных`.

### Канал для отказников и межсезонье
- **Механика:** отказник и неактивный уходят в канал (Ц-12): там ежедневный контент для всех, в межсезонье 2–3 материала в неделю без продаж. В бот — редкий повод: новый материал эксперта, только тем, кому интересна тема. Кто забрал материал, поднял руку и возвращается в путь: окно ближайшего потока или вовлечение по теме.
- **Инфостиль:** «Новый разбор: [тема] — [одна единица результата]. Если тема ваша, заберите здесь: [ссылка]. Если нет — по ней писать не буду».
- **Условие честности:** обещание «не буду писать по теме» выполняется тегом. Тема, закрытая «последним сообщением», не возвращается ничем.
- **Статус:** `гипотеза для холодных`.

### Невидимый рассказчик в касании
- **Механика:** история ведётся от лица клиента мечты, продукт появляется в ней естественно, без продажи в лоб (термин Романа). Структура: где был → чего хотел → стена → что пробовал и где сорвалось → находка → как сейчас. Читатель ставит себя на место героя.
- **Инфостиль:** «[Имя] [сколько времени] [что пробовала]. Срывалась на [где, когда — конкретная сцена]. Дело было не в силе воли, а в [причина]. Сейчас её обычный вторник: [распорядок]». Финал — «обычный день», а не роскошь.
- **Условие честности:** только реальные истории реальных клиентов с их согласия или история эксперта. Собирательный рассказчик — с пометкой, без цифр результата (M§4.5). Результат героя не обещается читателю.
- **Статус:** `гипотеза для холодных`; примечание: методика Романа.

### Серия для тех, кто пропустил эфир
- **Механика:** записался и не пришёл (Т-2, Т-3) — то же содержание в другой форме: запись или три коротких сообщения с основными мыслями эфира, затем предложение. Одно сообщение в день, до конца окна.
- **Инфостиль:** «Вы записывались на эфир [тема]. Если не получилось прийти — запись здесь: [ссылка]. Главное — с 12-й минуты».
- **Условие честности:** запись называется записью, а не «живым эфиром».
- **Статус:** `гипотеза для холодных`. Серия статей Романа (Ц-13) — `проверено на тёплой аудитории`.

### Запись на созвон с реальным лимитом
- **Механика:** на продукте выше 2 медиан окно ведёт не к оплате, а к записи (Ц-9). Срок — реальное число слотов или дата, после которой эксперт не берёт встречи.
- **Инфостиль:** «[Эксперт] проводит разборы до [дата]: осталось [N] слотов. Записаться: [ссылка]. На разборе: [что будет за 20 минут]».
- **Условие честности:** число слотов совпадает с календарём. Эксперт продолжит брать встречи — срока нет.
- **Статус:** `гипотеза для холодных`.

## 3. Анатомия одного касания

**Единица серии:** слот · день · мысль · история · доказательство · действие-метка (слово или вопрос — из карты). Одна мысль на единицу. Последняя строка — открытый вопрос, на который ответит следующая единица.

**Клик-сообщение:**
1. Первая строка — зачем открыть.
2. Ссылка в первых строках.
3. Что человек получит, нажав: 2–3 пункта.
4. Вторая ссылка или кнопка.
5. Подпись от имени эксперта.

**Сообщение окна, день 1:** повод (что можно получить) → условия → почему срок такой → что даёт продукт → ссылка или слово «условия» для ответа.

**Последний день окна:** срок → ссылка → что входит в продукт → что входит сверх → срок и ссылка. Ближе к концу текст короче: остаются срок и ссылка.

**Темы последнего дня** (вместо «Важно», «Доступ закрывается», «Предупреждение»):

| Время до конца | Тема |
|---|---|
| утро | «Условия [название] — до [время] сегодня» |
| −4 часа | «Осталось 4 часа: [условие]» |
| −1 час | «Последний час: [условие] до [время]» |

## 4. Библиотека углов

Угол — повод конкретного касания в серии, окне и повторной волне. Первые семь — из РБХ Романа, переведены в инфостиль.

### Как выглядит обычный день
- **Механика:** вместо мечты — распорядок дня после результата. Из обычного дня видно, что меняется завтра, и человек сверяет его со своим сегодняшним днём.
- **Инфостиль:** «Через [срок] обычное утро выглядит так: [3 конкретных действия]. Сейчас у вас [его слова из разговора]».
- **Условие честности:** распорядок — из реальных результатов клиентов эксперта.
- **Статус:** `из практики, цифр нет` (РБХ; `repos/promt-source-life/behavior-methodology.md`, «Образ будущего — это обычный день»).

### «Я не разберусь»
- **Механика:** страх сложности — частая причина отложить. Угол показывает, как устроен первый шаг и где помощь, если застрял. Работает как упроститель СТП («даже если…»).
- **Инфостиль:** «Первый урок — [длительность], после него один чек-лист. Если застрянете, [поддержка из оферты] ответит в течение [срок]».
- **Условие честности:** формат поддержки и сроки ответа — из оферты.
- **Статус:** `из практики, цифр нет` (РБХ).

### Где ошибаются новички
- **Механика:** проблема до решения создаёт напряжение (инфостиль 13.5). Человек узнаёт свою ошибку и видит, что её можно избежать.
- **Инфостиль:** «Три ошибки на старте [тема]: [1], [2], [3]. Вторая самая дорогая: [последствие]. В [продукт] она закрыта [чем]».
- **Условие честности:** ошибки — из облака незнания и чаши стресса паспорта, а не придуманные.
- **Статус:** `из практики, цифр нет` (РБХ).

### Обычный сценарий и другой
- **Механика:** два пути рядом: как обычно делают и к чему приходят, и как можно иначе. Сравнение по фактам: время, деньги, шаги.
- **Инфостиль:** «Обычно: [действие] → через [срок] → [результат]. С [продукт]: [действие] → через [срок] → [результат]. Разница — [одна единица]».
- **Условие честности:** обе стороны сравнения правдивы, «обычный путь» не карикатура. Конкуренты по имени не называются.
- **Статус:** `из практики, цифр нет` (РБХ).

### Всё уже готово
- **Механика:** снимает предстоящее усилие: человеку не надо собирать решение самому, план и материалы готовы.
- **Инфостиль:** «В [продукт] уже собраны: [план], [шаблоны], [чек-листы]. Ваша задача — [одно действие в день]».
- **Условие честности:** перечень совпадает с составом продукта в оферте.
- **Статус:** `из практики, цифр нет` (РБХ).

### Что будет, если ничего не менять
- **Механика:** честная версия угла «„потом“ не наступит». Вместо утверждения — вопрос, на который человек отвечает сам. Это мягкий извлекающий вопрос Романа.
- **Инфостиль:** «Если ничего не менять до [его срок], [проблема] решится сама или останется?»
- **Условие честности:** без давления виной («вы опять откладываете»). Ответ «решится сама» принимается.
- **Статус:** `из практики, цифр нет` (РБХ; `repos/prompt-spin-questions/spin-questions.md`, «Сейчас не время»; `repos/promt-source-life/spin-core.md`, 6.5).

### Маленький шаг
- **Механика:** цель на одну ступень выше текущего состояния, не дальше. Маленький первый шаг снимает страх «опять не получится»: прошлые срывы чаще всего шли от слишком крупного шага.
- **Инфостиль:** «Первый шаг — [действие на 10 минут]. Больше в первую неделю не нужно».
- **Условие честности:** шаг реально первый в программе.
- **Статус:** `из практики, цифр нет` (РБХ; `repos/promt-source-life/behavior-methodology.md`, «Лестница состояний»).

### «Хочу убедиться, что вы видели»
- **Механика:** ссылка на прошлое действие человека и следующий шаг. Не упрёк, а напоминание с поводом.
- **Инфостиль:** «Вы вчера забрали [магнит]. Если уже посмотрели — следующий шаг здесь: [ссылка]».
- **Условие честности:** действие записано ботом.
- **Статус:** `гипотеза для холодных`.

### Следующий логичный шаг
- **Механика:** человек уже показал, чего хочет (подписался, прошёл практикум). Угол связывает это действие с продуктом как продолжение, а не новую покупку.
- **Инфостиль:** «Вы пришли за [результат]. [Практикум] дал [часть 1], [продукт] — [часть 2]».
- **Условие честности:** без «я знаю, чего вы хотите»: опираемся на действие, а не на чтение мыслей.
- **Статус:** `гипотеза для холодных`.

### Реальный срок
- **Механика:** у условия есть дата, и это факт. Откладывание до последнего дня — норма, поэтому срок помогает решить.
- **Инфостиль:** «[Условие] действует до [дата, время]: [причина даты]. Потом — [что меняется]».
- **Условие честности:** причина и последствие реальные: старт потока, рост цены до реальной, закрытие набора.
- **Статус:** `гипотеза для холодных`.

### «Больше не пишу об этом»
- **Механика:** если реального срока нет, честный повод решить — прекращение сообщений по теме. Человек понимает: сейчас — или тема закроется сама.
- **Инфостиль:** «Это последнее сообщение про [продукт]. Ссылка останется здесь: [ссылка]. Дальше пишу о [другая тема] в канале».
- **Условие честности:** по этой теме бот действительно больше не пишет: тег `последнее_<продукт>`, предложение этого продукта в регулярных сообщениях тоже снимается.
- **Статус:** `гипотеза для холодных`.

### Новое условие в повторной волне
- **Механика:** только внутри одной повторной волны (Ц-6): после закрытия окна — новый короткий срок и новое реальное условие сверху. Повод решить появляется снова, и прошлое «нет» не становится окончательным. Вторая волна не ставится.
- **Инфостиль:** «Запись открыта ещё на двое суток, до [дата, время]: [причина]. Добавил [условие]: [что даёт]».
- **Условие честности:** в прошлом сообщении не было слов «больше не будет». Причина — реальная. Рассрочка новым условием не бывает.
- **Статус:** `гипотеза для холодных`.

### Ценность с опорой
- **Механика:** ценность элемента показана только проверяемой опорой: реальная прошлая цена этого элемента, цена аналога на рынке со ссылкой или посчитанная экономия (Р-5, M§5.6). Нет опоры — элемент без цены.
- **Инфостиль:** «Отдельно разбор рациона у нутрициолога стоит от [цена] ([источник]). В [продукт] он входит».
- **Условие честности:** без обвала «не N, а N/10», абстрактной «ценности» и суммы ценностей в разы больше цены (`decisions.md`, 2.1).
- **Статус:** `гипотеза для холодных`.

### Дробление цены
- **Механика:** цена — после ценности, с обоснованием и дроблением до дня, как доля результата (M§5.7).
- **Инфостиль:** «[Цена] за [срок] — это [сумма] в день. Рассрочка: [платёж] в месяц».
- **Условие честности:** без сравнения с мелочью («как две чашки кофе»): у недоверчивого покупателя это читается как обесценивание. Полная цена всегда рядом.
- **Статус:** `гипотеза для холодных`.

### «Давайте проверим, подходит ли вам»
- **Механика:** вместо уговора — предложение проверить соответствие. Снимает страх ошибиться и давление.
- **Инфостиль:** «Давайте проверим за 2 минуты: [3 вопроса по одному, ответ словами]. Если не подходит — так и скажу».
- **Условие честности:** «не подходит» реально говорится тем, кому не подходит (Б-7).
- **Статус:** `гипотеза для холодных`.

### «А если не получится»
- **Механика:** частое сомнение — неверие в себя, а не в продукт. Ответ — история такого же человека и что будет, если застрянет. «Худший случай» — через то, что человек сохранит (M§7.6).
- **Инфостиль:** «Если на второй неделе застрянете, [что делает эксперт]. Если не подойдёт совсем — по закону вернём деньги без споров, удержим только [что по оферте]».
- **Условие честности:** возврат — как условие оферты, дословно из `03-product.md`, п. 8, а не щедрость.
- **Статус:** `гипотеза для холодных`.

### История-демонстрация
- **Механика:** вместо описания выгоды — короткая история, в которой выгода видна. Читатель сам делает вывод.
- **Инфостиль:** «[Когда] клиентка прислала [конкретный след результата: фото, сообщение, цифру]. [Срок] назад было [как было]. Изменилось одно: [что]».
- **Условие честности:** история реальная, детали с согласия героя.
- **Статус:** `гипотеза для холодных`.

### Тем, кто уже пробовал
- **Механика:** обращение к тем, кто пробовал и не получил результата. Сначала назвать их опыт фактом, потом одно конкретное отличие (механизм, M§5.4), потом снова предложение.
- **Инфостиль:** «Если вы уже проходили [похожее] и бросили на [этап], обычно дело в [причина]. В [продукт] этот этап устроен так: [факт]».
- **Условие честности:** отличие есть в программе. Без «на этот раз точно получится».
- **Статус:** `гипотеза для холодных`.

### Неочевидная выгода
- **Механика:** кроме прямого результата есть результат результата — то, что он даёт в жизни. Новая выгода — новый повод написать.
- **Инфостиль:** «Кроме [прямой результат], клиенты отмечают [следствие]: [одна деталь]».
- **Условие честности:** выгоду называли сами клиенты. В нишах здоровья — без медицинских обещаний.
- **Статус:** `гипотеза для холодных`.

### Кейс похожего человека
- **Механика:** история клиента с похожей стартовой точкой показывает, что результат достижим для таких, как читатель.
- **Инфостиль:** «[Имя], [исходная ситуация]. Что делала: [3 шага]. Через [срок]: [результат]. Если ваша ситуация похожа — [действие]».
- **Условие честности:** кейс реальный, цифры подтверждены, есть согласие клиента. Без обещания читателю того же результата. Кейсов нет — бета-группа (О-6).
- **Статус:** `гипотеза для холодных`.

### «Всё ли в порядке?»
- **Механика:** человек пропал после активности. Вопрос о нём, а не о покупке, снимает напряжение и даёт повод ответить.
- **Инфостиль:** «Вы давно не заходили в [где]. Тема ещё актуальна? Если нет — напишите, перестану присылать».
- **Условие честности:** ответ «не актуально» выполняется.
- **Статус:** `гипотеза для холодных`.

### Вопрос вместо продажи
- **Механика:** короткий вопрос «что вас остановило?» даёт два результата: человек снова вступает в диалог, а эксперт узнаёт новые возражения для базы знаний бота. Ответивший получает живой ответ (Б-5).
- **Инфостиль:** «Один вопрос: что помешало начать [продукт]? Цена, время, формат или что-то другое?» — ответ словами.
- **Условие честности:** на ответ реагирует человек по существу, а не бот тем же оффером.
- **Статус:** `гипотеза для холодных`.

### Кому не подходит
- **Механика:** честное «кому не подходит» вместо давления виной. Те, кому подходит, узнают себя увереннее, остальные уходят до покупки и возврата. Для недоверчивого покупателя это довод «не разводят» (M§4.8).
- **Инфостиль:** «[Продукт] не подойдёт, если [условие 1] или [условие 2]. Подойдёт, если [ситуация клиента мечты]».
- **Условие честности:** условия реальные, совпадают с квалификацией бота (Б-7).
- **Статус:** `гипотеза для холодных`.

## 6. Что выброшено и почему

| Приём | Почему убран |
|---|---|
| Стек дедлайнов: несколько сроков подряд с продлениями | повторные «последние» шансы учат, что сроки условные; заменено одной повторной волной (Р-8) |
| Две-три волны продаж после закрытия ссылки | то же; волна одна, затем «последнее сообщение» и канал |
| Шесть сообщений в день в мессенджере | почтовая норма; в боте каждое сообщение — уведомление (M§4.2) |
| «Возможно, верну полную цену — ещё не решил» | выдуманный якорь |
| «Пакет бонусов стоимостью N» без опоры | сумма без источника; заменено ценностью с опорой (Р-5) |
| Обвал цены «не N, не N/3, а N/10» | маркер инфоцыгана для недоверчивого покупателя (Р-5) |
| Выдуманная история как основа продажи | враньё; только реальные истории, собирательный рассказчик — с пометкой |
| Повторное открытие после «закрыто навсегда» | «навсегда» — только если правда навсегда |
| «Назовите меня сумасшедшим, но я удивлён…» | давление виной |
| Цена «обычно N, сейчас половина» без продаж по полной цене | якорь, если полная цена не действовала |
| Скидка за полную оплату | рассрочка заложена в цену с начала (В-41) |
| Удаление неактивных из базы | заменено тишиной без удаления (Р-11) |
| Продажа сразу после подписки холодным | снимает сливки и сжигает остальных; продажа по порогу (Р-1) |
| Тающая скидка, «осталось 15 мест» без реальной ёмкости | ложная срочность (M§7.10) |
| Сравнение цены с мелочью | обесценивание (M§7.10) |

## 7. Пробелы

1. **Нет данных по холодной аудитории в РФ** ни по одной цепочке. Проверены только отметки до закрытия ссылки (РБХ, 3 человека — малая выборка) и серия статей Романа на тёплой базе.

4. **Углы РБХ** перечислены со слов Романа. Тексты исходных сообщений и конверсия по каждому углу не найдены в файлах проекта.
5. **Согласие клиентов на истории и кейсы** — строка в `06-legal/` у Архитектора (`agents/05-architect.md`, шаг 7), состав — `knowledge/texts.md`, §9 `[ДОПУЩЕНИЕ]`.
6. **Снятие цепочек при оплате и смене состояния** проверяется при прогоне бота человеком в выбранном сервисе по `06-bot/test-dialogs.md`: сервис должен уметь снимать запланированные сообщения по событию (M§12.3).
