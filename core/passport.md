# Паспорт проекта — шаблон

**Что это:** единственный источник правды о проекте одного эксперта. Его читают все агенты, но в каждый раздел пишет только агент-владелец. Подробные материалы лежат в отдельных файлах (см. `handoff.md`). Здесь — выжимка и ссылки на них. Шапки (`core/handoff.md`, раздел 2) у паспорта нет: статусы и версии разделов — в разделе 0.

**Правила заполнения:**
- Факт о рынке — с источником и датой: `(Wordstat, 2026-10)`.
- Нет данных — `[нужна цифра: что именно]`. Выдумывать нельзя.
- Решение без подтверждения человека — `[ДОПУЩЕНИЕ: что и почему]`.
- Пересказ слов эксперта — `[со слов эксперта]`.
- Если раздел-источник изменился, все разделы ниже получают статус `устарело`, пока владелец их не обновит.

| 7. Проверка | Контролёр | не начат | — | — |

Сейчас: —

Пауза: нет

**Условия человека.** Всё, что человек поставил условием на любой развилке («без эфиров каждую неделю», «не дороже 15 000 ₽»), Фиксик записывает сюда его словами. Все агенты читают этот список и не предлагают вариантов, которые его нарушают.

| № | Условие (словами человека) | Где сказано | Дата |
|---|---|---|---|

Статусы: `не начат` → `черновик` → `проверено` (агентом-проверяющим) → `утверждено` (человеком) / `устарело`.

Статусы ожидания — раздел или строка не сделаны и ждут входа:
- `нужны данные` — нет факта, без которого материал стал бы враньём (дата, вместимость, площадка, кейс). В графе «Файл» — `[нужны данные: что именно]`, вопрос — Фиксику для человека. Пришли данные — работа с начала, статус `черновик`.
- `ждёт текст` — только у строк Арт-директора: текст в `06-texts/` не `утверждено` или в нём остались варианты без выбора человека. Текст утверждён — Арт-директор делает материал, статус `черновик`.

Не ожидание, а пометка замены:
- `черновик без голоса` — только у продающих строк Текстов: эксперт после запроса не прислал сырья совсем, материал написан ровным инфостилем без историй, кейсов, цифр и мыслей эксперта (`knowledge/texts.md`, §2.8). Как финальный не утверждается; человек может запустить его, в README проекта — пометка «заменить». Пришло сырьё — Тексты в режиме «правки», статус `черновик`.

Фиксик считает проект готовым, только когда ни у одной строки нет статуса ожидания.

## 3. Продукт

*Владелец: Продуктолог. Подробно: `03-product.md`.*

- **Продуктовая матрица ниши** (ориентир, показывается человеку целиком): сегменты и типичные цены (источник, дата).
- **Коридор:** текущая ступень (формат / ответственность / комфортный чек) = ___; собираем ближайшую ступень и одну выше. Верх цены и порог считаются по полной цене за весь срок продукта.
- **Порог дорогого чека:** медианная начисленная зарплата по РФ = ___ ₽ (Росстат, период, дата). Зоны: ниже 1 медианы — ниже порога; 1–2 — граница; выше 2 — выше порога.

| Роль | Где в коридоре | Продукт | Формат | Результат (действие) | Срок | Полная цена | Зона порога | Как продаётся |
|---|---|---|---|---|---|---|---|---|
| Магнит | не ступень | | | | | 0 ₽ | — | |
| Вход (первое обязательство) | практикум с ценой 0 / платный мини-шаг (тест второй когорты) | | | | | | | |
| Основной | ближайшая / на ступень выше | | | | | | | |
| Довесок | галочка на оплате, не отмечена заранее | | | | | | | |
| Следующая ступень (план) | вне коридора, не собираем | | | | | | | условие запуска: |

Основной продукт в варианте один: его продаёт воронка. Магнит — не ступень: он бесплатный и путь за человека не проходит. Вход ведёт к основному: по умолчанию — бесплатный практикум с обязательным действием. Основной выше 2 медиан — практикум по желанию, основной путь — заявка и диагностика.

- **Что бесплатно, что платно:** бесплатное даёт «что», «почему» и маленькую победу, но не проходит путь за человека. Крючок, бесплатное и платный продукт — об одной боли.
- **Оффер** (дословно; бонусов нет — так и пишется):
- **Первое обязательство:** практикум 3–5 дней (когорта 1) / платный мини-шаг (тест когорты 2):
- **Стек:** элемент — какую проблему снимает — чем подтверждена ценность (прошлая цена / аналог со ссылкой / посчитанная экономия; опоры нет — элемент без цены):
- **Рассрочка:** банковская — да; внутренняя — да / нет (только у продукта с живым сопровождением и чатом). Цена с комиссией рассрочки, скидки за полную оплату нет:
- **Гарантия** (дословно, совпадает с офертой): законный возврат дословно + условная гарантия результата (шаги X, Y, Z) + гарантия процесса (для дорогого сопровождения):
- **Допродажи:** довесок на оплате; шаг после оплаты; основная допродажа на контрольной точке:
- **Непрерывность:** сезоны, чат выпускников:
- **Бета-группа:** да / нет, цена (сниженная или символическая, не бесплатно), обязательства участника:
- **Реальные ограничения:** дедлайны, места, рост цены — что и почему. Только настоящие. Продукт без живого участия — мест нет.
